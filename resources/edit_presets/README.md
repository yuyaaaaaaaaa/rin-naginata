# 編集モードのプリセット

設定画面の「プリセット」から選んで適用できます（適用前の定義は `edit_mode.backup.json` に退避されます）。公式準拠（薙刀式v18マニュアル）の定義はアプリに内蔵されていて、同じメニューからいつでも戻せます。

| ファイル | 内容 |
|---|---|
| `author_example.json` | 作者の個人設定。IJKL 式のカーソル移動、演算子記号の面、曜日・年月日を出す固有名詞面（D+V）、矢印文字面（U+I）など。単打の T/Y は「（」「）」 |

自分で作った定義（`~/Library/Application Support/Rin/edit_mode.json`）を「ファイルから読み込む…」で他の人と共有することもできます。
